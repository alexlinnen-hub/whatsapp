# Focus Group customer onboarding guides

Static site published with GitHub Pages. Edit the HTML in place and push to `main`; the live link updates within a minute or two, so customers always see the latest version.

- `index.html`: list of guides
- `whatsapp/index.html`: connecting a customer's WhatsApp Business number to their ElevenLabs AI agent
- `assets/style.css`: shared styles. Brand colours and fonts are the CSS variables at the top of the file.

To add a guide, copy `whatsapp/` to a new folder, edit it, and add a card to `index.html`.
